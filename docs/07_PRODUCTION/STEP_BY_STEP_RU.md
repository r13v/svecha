## 1. Пространство и движение — реализовано

- [x] Двор и подход, храм около 7 × 11 м, дверь с раздельными створками, столик и подсвечник.
- [x] Движение CharacterBody3D, капсула, взгляд мышью, один луч взаимодействия длиной 1,65 м.
- [x] Закрытая дверь блокирует проход, открытая пропускает игрока; стены блокируют действие лучом.
- [x] Автоматическое прохождение полного маршрута обычным движением и коллизиями, без телепортаций между ключевыми точками.
- [x] Внешняя поверхность имеет единый уровень коллизии; с дорожки можно сойти и вернуться. Двор ограничен видимой низкой оградой.

## 2. Свеча и эпизод — реализовано и проверено

- [x] В руке не больше одной свечи; повторное E во время действия не создаёт копии.
- [x] Новая свеча не расходуется до зажигания; незажжённая не завершает установку.
- [x] Зажигание возможно от горящего фитиля, выбранного лучом; источник повторно проверяется после движения руки.
- [x] В свободное гнездо переносится тот же экземпляр свечи; после установки руки освобождаются.
- [x] Свечи игрока и окружения непрерывно расходуются по монотонным часам, даже вне кадра.
- [x] По запросу пользователя срок новой свечи установлен в 20 минут (1200 с) активного горения; окружение использует тот же срок с разными остатками.
- [x] Пауза останавливает расход, продолжение не вычитает время паузы.
- [x] При 15/30/60/144 FPS одинаковый интервал расходует одинаковый запас; большой шаг времени не теряется.
- [x] Укорачивается только воск; основание и диаметр сохраняются; фитиль, огонь и свет следуют за верхушкой.
- [x] Полное догорание срабатывает один раз: нулевой запас, пламя и свет выключены, остаются воск и обгоревший фитиль.
- [x] Сгоревшую свечу нельзя зажечь снова. Догоревшую в руке можно заменить у столика; погасшее окружение не создаёт огонь.
- [x] Установка остаётся выполненной после догорания; занятое место не освобождается автоматически.
- [x] Выход после установки завершает эпизод; ранний выход не завершает его.
- [x] Повтор восстанавливает исходную сцену и состояния.
- [x] В отдельных приложении и редакторском запуске есть старт, пауза, продолжение, повтор и выход.

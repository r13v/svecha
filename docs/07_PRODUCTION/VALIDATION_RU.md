Основные команды из корня:

```sh
./tools/godot --headless --editor --path game --import
./tools/godot --headless --path game --script res://tests/check_candle_assets.gd
./tools/godot --headless --path game --script res://tests/check_game.gd
./tools/export_macos.sh
```

Проверка именно упакованных ресурсов, без включения тестов в приложение:

```sh
./tools/godot --headless \
  --main-pack "$PWD/builds/macos/Svecha.app/Contents/Resources/Свеча.pck" \
  --script "$PWD/game/tests/check_game.gd"
```

Проверка выхода во время действия с настоящим звуком и окном:

```sh
./tools/godot --path game --script res://tests/check_game.gd -- --quit-during-action
```

Тест проходит основные перемещения через тот же CharacterBody3D и действие через тот же RayCast3D, что и игрок. Для независимых отрицательных сценариев тест переставляет камеру. Сокращённые интервалы и вызовы расчёта в тестах не меняют срок свечей обычной игры.

## Горение и ограничения проверки

Все горящие свечи расходуются в масштабе 1:1. Пауза по Esc и потеря фокуса окна останавливают симуляцию; вне поля зрения свечи продолжают расходоваться. После закрытия приложения отсчёт не ведётся, повтор запускает исходное состояние.

По запросу пользователя полный срок новой свечи изменён на **20 минут (1200 секунд) активного горения**, параметр `candle_lifetime_seconds` в `church.gd`. Свечи окружения используют тот же полный срок, но начинают с частично израсходованным воском. Отсчёт новой свечи начинается при зажигании; паузы исключены. Это выбранная длительность для игры, а не замер реального образца. После изменения повторно выполнен `check_game.gd`: PASS, 0 failures. Проверка использует расчёт расхода и переходов; двадцатиминутное наблюдение по секундомеру не проводилось.

Рука, окружение и синтезированные звуки — первый игровой вариант. Движение расплавленного воска, тепловая модель и жидкость не симулируются: для текущего эпизода реализован конечный запас горючего и изменение высоты. Публикация, notarization и проверка на Intel Mac, Windows и Linux не выполнялись.

Локальные журналы находятся в `.tools/checks/` и исключены из Git. Сохраняемые результаты: этот отчёт, PNG, JSON, задания, исходники и приложение в `builds/macos/`.

В диагностическом режиме `--verbose` Metal сообщает об автоматическом преобразовании RGB8-текстур в RGBA8. Обычные финальные журналы импорта, проверок, экспорта и трёх release-запусков не содержат ERROR.

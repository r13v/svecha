# Материал известнякового пола

`floor_albedo.png` и `floor_normal.png` созданы встроенным image_gen по концепту № 03 и затем по полученному цветному слою. Фактический размер обеих карт — **1254 × 1254 px**. Карта нормалей использует согласованное расположение камней и сколов; её сила в материале уменьшена до 0,55.

Промпты: `../prompts/floor_albedo.txt` и `../prompts/floor_normal.txt`. Рабочие копии и SHA-256 — в `game/assets/textures/limestone/`. Это текстуры для полноценной 3D-поверхности, а не изображение, подставленное вместо игрового кадра.

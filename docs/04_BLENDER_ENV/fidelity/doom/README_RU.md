# Doom в Web-сборке — историческая проверка ноутбука, 14 сентября

С 15 сентября ноутбук заменён [терминалом помощи кошкам](../terminal/README_RU.md). Ниже сохранены кадры предыдущей итерации.

Кадры сняты в Chromium с экспортированным PCK. Внешний сценарий прошёл обычный маршрут до ноутбука; управление ноутбуком проверено через браузерный ввод.

- [Ноутбук во дворе](approach.png).
- [Первый уровень на 3D-экране](playing.png).
- [Меню Doom по Esc](menu.png).
- [Проверка входа, ввода, паузы, выхода и повторного сеанса](browser_verification.json). Удержание WASD/Ctrl выполнялось DOM-событиями клавиатуры через Godot; Esc и F10 — командами реального ввода браузера.
- [Проверки и ограничения](verification.json); [размер экспорта](web_size.json).

Захват физической мыши остался непроверенным: заблокированная сессия macOS возвращает WrongDocumentError для Pointer Lock. Клавиатура работает; при отказе захвата выход из ноутбука корректно возвращает обычное меню паузы. Ненулевой звуковой сигнал проверен в Web Audio; субъективная оценка звука и полное прохождение эпизода не выполнялись. Публикации этой версии не было.

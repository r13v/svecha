# Терминал PurrMačka со скрытой диагностикой

Кадры сняты в Chromium из экспортированного Web PCK 15 сентября 2026. Терминал заменяет прежний ноутбук. Проверочный сценарий открывает дверь и проходит к нему обычным движением; дальнейшие касания, Esc и F10 выполняются настоящим вводом браузера.

- [Корпус в Blender](model_blender.png); материал и ориентация затем проверены в игровом освещении Godot. Страницы дисплея создаются в игре.

- [Doom](doom.png), [его меню по Esc](doom-menu.png).

Кнопка пожертвования проверена реальным кликом: открылась отдельная вкладка `https://purrmacka.org/ru/`. Платёж не совершался. На главной странице и в диагностике до первого выбора теста 1993 года отсутствовали iframe Doom и запросы его файлов.

В технической сессии macOS Pointer Lock отклоняется с WrongDocumentError; физическое управление мышью в Doom остаётся для ручной проверки. Обычные клики по экрану, клавиатура и корректный возврат при отказе захвата проверены. Субъективное прослушивание и полное прохождение эпизода не выполнялись. Версия не опубликована.

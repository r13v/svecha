# «Свеча» — материалы для производства

Структура адаптирована из `dust-horizon-template/` под короткую игру о посещении православного храма. Документы и визуальные материалы находятся в `docs/`; исполняемый Godot-проект находится в `game/`, Blender-исходники — в `art/`.

## Как пользоваться

1. Запустить `builds/macos/Svecha.app` или `./tools/godot --path game`.
2. Пройти эпизод: дверь → столик → горящая свеча → свободное гнездо → выход.
3. Сравнить текущую сцену с девятью концептами и листом предметов.
4. Посмотреть [проверки и ограничения](../07_PRODUCTION/VALIDATION_RU.md); затем уточнять художественные решения.

Концепт-арт — цель по настроению и композиции. Размеры, точное положение предметов, коллизии и исполнение жестов проверяются в игровом прототипе. Это не готовые 3D-ассеты и не инструкция по церковным обычаям.

## Правило источника

Полный промпт каждого изображения — в `02_CONCEPT_ART/prompts/`; готовое изображение — в `generated_images/`. [MANIFEST.json](../02_CONCEPT_ART/MANIFEST.json) связывает их, хранит референсы, разрешение и контрольную сумму. При новой версии сохранять новый файл, а не затирать предыдущий вариант.

В исходном шаблоне заимствована организация работы. Его промпты про пустошь, оружие и ремонт автомобиля в проект не перенесены. Сами файлы `dust-horizon-template/` не менялись.

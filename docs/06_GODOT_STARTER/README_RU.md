# Запуск Godot-проекта

Проект: `game/project.godot`. Стартовая сцена `scenes/church.tscn` собирает проходимый храм из 13 Blender-ассетов и простого окружения Godot. Это полноценный интерактивный прототип; `asset_review.tscn` сохранена как отдельный просмотр геометрии.

```sh
./tools/godot --path game
./tools/godot --editor --path game
./tools/godot --path game res://scenes/asset_review.tscn
```

Нажать «Войти в тишину». WASD — ходить, мышь — смотреть, E — выполнить подсказку под прицелом, Esc — приостановить или продолжить. Сначала открыть дверь, взять свечу со столика справа, подойти к подсвечнику, навести прицел на горящий фитиль и нажать E. Затем навести на свободное ближнее гнездо и установить свечу. Для завершения выйти наружу. В меню есть повтор и выход.

Скрипты: `player.gd` — движение и обзор; `candle.gd` — конечный запас воска и изображение; `church.gd` — сборка пространства, действия, меню и завершение. Горение использует монотонные часы и исключает паузу. Реальные изображения икон и сведения о правах находятся в `game/assets/icons/` и [источниках](../07_PRODUCTION/ASSET_SOURCES_RU.md).

Проверки и сборка описаны в [отчёте](../07_PRODUCTION/VALIDATION_RU.md). По решению пользователя полный срок новой свечи — 20 минут (1200 с) активного горения. Игровой масштаб времени — 1:1.
